# Meridian agent instructions

Follow the root agent instructions, component/patent policies and maintenance gate. Start with the matching `context` route and current project/decision records.

For every engineering, model, qualification, optimization or scientific-report task, read [CONTRACT.md](CONTRACT.md) in full, the relevant specifications, source register, research memory and evidence. That contract preserves the original scientific and procurement requirements. Documentation/branding tasks read engineering evidence when making engineering claims.

Physics/measurements > SPICE > tests > numerical optimization > reasoning > intuition. Keep all 14 families alive. No device selection, matching, hidden trimming, silent threshold/range changes or performance credit from unknown/missing behavior. Proposals are not results; unknown capsule safety/mechanics cannot become hardware ratings or noise/SPL/polar claims.

Run `./run verify` after relevant code/model changes and `./run evaluate <id>` for a candidate; exit 2 means unqualified. Freeze sources for simultaneous evaluators. Never overwrite parents: structural children use `search/mutate.py`. Retain raw failures, snapshots, seeds and comparisons. No eligible winner without complete qualification and measurement evidence.

Update phase reports and research memory when evidence changes. New batches require dated inventories, integrity checks and verified private backup coverage. Run the root documentation gate as well as applicable scientific checks. Procurement, patent screening and physical qualification remain separate; no purchase/contact/publication is authorized by this file.
