# Repository quality contract

[Contributing](CONTRIBUTING.md) · [Rules](docs/quality-rules.md) · [Validation](docs/validation.md) · [Owner decision](docs/decisions/2026-10-09-repository-structure.md)

Owner-directed revision: 2026-10-09; repository-wide. Component/patent/scientific contracts retain authority. A repository pass promotes no project readiness.

`project.json` owns current facts/evidence; configuration owns modules/routes/classifications. Decisions retain rationale/originals. Records retain observations, failures, parents, cohorts and hashes; generated views reproduce them without inventing unknowns.

Maintained UTF-8 text, including code/configuration/generated text, has a **15,000-character** ceiling. Shared onboarding includes every mandatory policy and has the same ceiling; current state stays below 300 words. Entry routes stay within50,000 characters; extra required evidence loads without a cap. Scientific correctness takes priority over reading size. SVG/media and hash-protected originals/licence material retain their scope; no general waiver exists.

Follow the [completion sequence](CONTRIBUTING.md#complete-a-change). Quality/tooling changes need dated decisions and regression coverage. Recurring defects become fixtures; audits use existing records. No scheduled jobs or extra ledger.

Commit/merge-commit/patch/push gates inspect selected content and run pinned lint/fast regressions without rewriting, staging or downloading. One CI workflow repeats checks without private originals/simulations. Scientific edits retain full lab qualification, thresholds, budgets and 14 architecture families.

Never rewrite frozen bytes, hide failures or weaken requirements for a pass. Invariant/budget changes need explicit owner direction, dated rationale and measured impact. Preserve scientific entry points and backup compatibility. New batches need inventories, verified integrity and privately restored captures. Full preservation needs independent persistent storage; retain [legacy gaps](docs/legacy-evidence.md). Reruns/reacquisition cannot recover originals. [Private procedures](docs/maintaining-repository.md#private-evidence) reject unsafe/changing inputs and exclude credentials/caches.
