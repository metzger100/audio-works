## Implementation and backend limits

All six initial attempts use actual nominal parts. The power path takes both P48 legs through2.2kΩ resistors, then a divider-fed NPN emitter-follower rail, real divider current and filtered polarization. Ten series1MΩ production resistors realize the10MΩ polarization filter; no unavailable ideal10MΩ value is claimed.47Ω/47µF legs drive the actual cable/preamp fixture. Real models include their output-driver current and stationary noise when that analysis is supported. Different NPN output structures are preserved as children instead of forcing failed CMOS macros onto every mechanism.

The semiconductor library is used only within its documented scope. OPA197 agreement at grounded linear test points does not validate P48/floating/nonlinear behavior. Original NPN vendor DC failure and the one-node emitter child are preserved in the library lineage; missing KF, typical capacitances and missing joint production bounds are not repaired by invention. Nominal JFE150 behavior is not a manufacturer-bounded no-selection population. A missing process-corner test remains incomplete.

Physical resistors/capacitors carry their catalogue tolerances. The seeded population is **independent tolerance stress**, not a measured production distribution. Original capsule/environment uncertainty ranges, seeds and qualification thresholds remain unchanged. High-R shunt capacitance and guard geometry/leakage are explicit assumptions: guard5pF has0.5–9.5pF stress,1GΩ shunt0.2pF has0.02–0.38pF stress; these are additional geometry controls, not narrower capsule uncertainty. Film/electrolytic ESR, insulation, temperature laws, thick-film excess noise and high-R voltage coefficient are not fully modeled. No BOM is build-ready.

The Yageo100pF realization retains5% tolerance,100V rating and the manufacturer's10GΩ minimum insulation anchor. Its series loss control derives from0.1% DF at an explicitly assumed1MHz conversion, with a decade-wide loss sensitivity and10GΩ–100TΩ insulation scenario. Constant ESR is not a validated broadband or temperature model. Lowering the BJT reset resistance is a recorded structural DC-authority experiment, not hidden unit adjustment. Complete supported tests are rerun for each child; equal nominal values do not give substitute-equivalence credit.

The backend first establishes operating point and all modeled terminal currents. New accounting sums per-device V·I, explicit resistor losses and capsule leakage, compares these with actual DUT terminal power and records per-device KCL residuals. A1e-4 relative energy-closure check is an additional falsification invariant. Native macro terminal accounting still cannot establish thermal/SOA safety. Candidate circuit, metadata, BOM, hypothesis and notes now freeze together; changes to any implementation file during evaluation invalidate the run. Existing immutable records retain their original formats/bytes.

Carrier candidates use a distinct documented periodic mechanism path. Ordinary DC-linearized noise, AC/headroom and transient audio scores are explicitly incomplete rather than misapplied to a periodically biased demodulator. Four pressure/carrier on/off controls and timestep refinement are supported. The independent passive-island test checks charge-conservation sidebands, and a synthetic AM oracle checks extraction. The [isolated bridge/demodulator control](carrier_island_control.py) additionally tests actual SPICE synchronous recovery against an analytic filter result. Periodic noise, RF folding/correlations, oscillator AM/PM, stochastic PSD confidence and a physical demodulator/power implementation remain unsupported. An unsupported carrier-noise test does not reject the architecture.

## Failures, physical implications and unknowns

Initial OPA-containing attempts0001–0004/0006 failed the operating-point convergence screen. A [preserved initialization probe](probes/opa_initialization_2026-10-09/results.json) tried explicit nodesets without altering device models/specification; it also failed to produce valid operating-point data. Those are implementation/model failures, not proven impossibility of the input families. The CMOS-with-NPN-output children preserve the CMOS mechanisms long enough to expose the same unresolved macro compatibility. It would be inappropriate to replace the input devices by ideals and report an architecture advantage.

The BJT charge hypothesis has a physically supported tradeoff: base current must have a DC return, and reset conductance plus very large Cfb reduces the pressure-to-voltage conversion. The actual simulated response/noise, not this argument alone, determines whether the implementation fails budgets. Missing bipolar1/f behavior prevents a complete architecture-noise claim even if a stationary numerical noise result exists. Electrical-model failure or a budget miss applies to the recorded implementation; no family is retired.

No acoustic polar response, thermal/mechanical capsule noise, collapse/pull-in, safe polarization, physical distortion/overload or device SOA is established. The nominal rear-pressure stimulus remains zero, so this batch does not separately qualify MIC-34-M and MIC-34-C acoustics. Simulated polarization is a circuit result, never a safe hardware rating.
