# Meridian reports and research layout

Date:2026-10-10. Owner asked for direct inspection and token-efficient cleanup of Meridian, including reports, after the repository-wide structure implementation.

## Decision

Keep short current findings with linked exact evidence, conditions, failures, limits and next actions. Remove repeated policy/background paragraphs and empty outline stubs. Keep the full scientific contract and all required conditions in scoped evidence. Setup/interface documentation is loaded for those tasks. Read the prompt plan when executing a numbered task; unrelated routes retain the scientific contract and relevant evidence without preloading that plan. Concise memory points to original reports instead of repeating them.

Move23 executable controls/reporting helpers from research to tools/controls and tools/reporting; name helper modules by purpose rather than numbered stages. Subject directories retain current research. Hash-protected dated originals and private legacy source folders keep their original paths/bytes; the authored hubs explain their provenance.

Replace literal-fragment report templates with bounded derived tables/plots under results/reports. Generators preserve maintained findings and frozen records. Derived comparison identities retain the exact original source-relative names/hashes rather than renaming provenance strings. Regression coverage checks them against frozen records. Future scientific manifests capture the relocated imported modules; the initial renderer selects original-cohort verification rather than the latest unrelated cohort. Old file references resolve through the path register.

## Mechanical coverage

The shared gate rejects repeated substantial Markdown paragraphs and empty sections. Required contract links are real Markdown links so path errors fail. [Structure fixtures](../../tests/quality/test_structure.py) reproduce duplicate/empty prose. [Reporting regressions](../../meridian-microphone/lab/tests/test_reporting.py) protect narratives/original cohorts; [manifest coverage](../../meridian-microphone/lab/tests/test_device_models.py) protects relocated imports. [Direct command tests](../../meridian-microphone/lab/tests/test_parts_database.py) run documented search/count/audit commands without an inherited Python path and validate the relocated registry default. Existing Git/recovery tests remain required.

## Boundaries and impact

No specification, thresholds, budgets, resolved scientific values, identities, parents, original failures or frozen hashes change. No sourcing/patent/physical evidence is promoted. Original reports remain indexed and hash-protected. No new exception, scheduled job or process ledger is added.

Measured before/after reading sizes, report sizes, runtimes, verification and private recovery belong in [validation](../validation.md). Independent persistent backup and89legacy source gaps remain incomplete. This decision authorizes local cleanup; pending remote publication is a separate approval.
