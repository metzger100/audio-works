# GitHub authority and archived recovery tasks

Date: 2026-10-11. The owner requests GitHub as canonical storage and removal of the old missing-source recovery item. This explicitly supersedes the mandatory private-backup and ongoing historical-recovery requirements in earlier repository/storage decisions.

## Authority and scope

`https://github.com/metzger100/audio-works` is authoritative for committed code, specifications, compact experiment records, reports and history. Local repository checks inspect the selected working tree, index or commit; remote synchronization must be checked separately after an authorized push. Repository status no longer depends on a private independent-storage attestation.

Original ignored waveforms, exports and vendor bytes remain local supporting evidence. Private capture/restore is optional. GitHub authority does not assert that ignored files were uploaded, that absent original bytes were recovered, or that an archived experiment is reproducible. Scientific reproduction/qualification still needs its actual original inputs and all existing behavior, measurement, sourcing and patent evidence.

## Historical records

The old missing-source audit and ledger move unchanged into protected history. Their recovery item is retired from current status and contributor work. Frozen experiments retain their exact manifests, hashes, failures and parent relationships; deleting manifest entries would change the recorded experiments. Full original-evidence audits and optional backups continue distinguishing known archived omissions from new missing or damaged inputs.

The gate resolves a protected file's registered destination before comparing its Git blob and execute mode. Provenance remains tied to the unchanged original revision and SHA-256. This supports archival relocation without permitting changed bytes or deleted protection. Earlier checkouts and backups continue accepting the ledger's previous location.

## Impact and verification

Current reports and prompts follow the new storage scope. Historical validation receipts retain the outcomes observed at their dates. No scientific threshold, evaluation budget, family, implementation identity or qualification state changes.

[Validation](../validation/2026-10-11-github-canonical.md) records retained bytes, route sizes, repository regressions, fresh-clone behavior and optional archive recovery. The change removes a storage prerequisite; it provides no new evidence-completeness or engineering-readiness claim.
