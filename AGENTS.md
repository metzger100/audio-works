# Repository agent instructions

Read the relevant project description and decision log before changes. Use `python3 tools/project.py context <route>` to choose the required reading; Meridian work follows `meridian/lab/AGENTS.md` and its scientific contract.

Always read [COMPONENTS.md](COMPONENTS.md) and [PATENTS.md](PATENTS.md). Standard, documented, currently obtainable production parts and dated private small-quantity sourcing/delivered costs to Germany are mandatory. Realize optimizer proposals as actual BOMs and requalify values, tolerances and substitutes. Preserve unsourced concepts as research; never invent availability or prices.

Patent screening requires candidate-linked claims, territory and current official status. Credible unresolved blocking risks hold affected prototype, manufacture and build-publication gates. Originality, licensing, private DIY use and simulations are not clearance. Preserve experiments, continue unaffected research and refer material legal uncertainty for professional review. No purchase, contact, payment, licence acceptance or external publication is authorized here.

## Mandatory completion gate

Follow [QUALITY.md](QUALITY.md) and [CONTRIBUTING.md](CONTRIBUTING.md). Update current facts in `project.json`, rationale in decision logs and evidence in its original records. Classify new modules and maintain reading routes. Run `python3 tools/project.py refresh`, then `python3 tools/project.py check` and applicable tests before calling work complete. Scientific changes retain all existing qualification requirements.

Preserve original failures, parent relationships, snapshots and hashes. Verify and privately back up new research batches; report missing backup coverage as incomplete. Never modify frozen evidence or weaken rules/budgets to obtain a passing check. Budget/invariant changes require explicit owner direction and a dated decision with rationale and measured impact. Read only needed context, but never omit evidence required for correctness. Install the local commit hook with `python3 tools/project.py hooks install` in each new checkout. Report checks and remaining unknowns honestly.
